# 表面跟踪支持的设备和平台
表面跟踪功能支持 Android 和鸿蒙系统的手机及平板，不支持 PC、MR 头显、可穿戴眼镜。 开发者可以通过 Unity 或 Native 进行开发。
## 额外的硬件要求
除了摄像头之外，表面跟踪还需要设备支持陀螺仪或加速度计。
> **注意**
虚拟的陀螺仪、自定义相机等均不可用表面支持功能。
